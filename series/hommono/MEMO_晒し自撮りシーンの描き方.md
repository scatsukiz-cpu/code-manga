# 晒し自撮りシーンの描き方メモ（『知らなければ』第3話 コマ31-2で検証）

作品中に1〜2回しか出ない「事後の自撮りが晒される → 主人公が見てショック」の場面用。
SNS投稿（PG12程度）を前提に、絵の段階では服を着せ、メッセージアプリの吹き出しで隠して「裸に見せる」。

## 基本方針
- 男は上半身裸、女性は**肩紐なしの白いチューブトップ**を着せる（肩・腕・鎖骨は素肌）
- 写真は腰までの自然な自撮り構図で描く。鎖骨でトリミングすると「切った画像」に見えて雰囲気が出ない
- 絵が出来てから、チューブトップの上端〜下端を**吹き出しで完全に覆う**
  → 素肌の肩しか見えないので何も着ていないように見え、セリフ（例「ちょ、澪、おっぱい丸出しじゃん😆」）が成立する
- 次のコマは、スマホの光に照らされた主人公の顔のアップ（見開いた目、冷や汗、縦線、集中線）

## 吹き出し（チャット）の置き方
- 吹き出しはグループトーク風：アイコン＋名前＋白い吹き出し＋時刻
- **隠す役の吹き出しは1つを大きく**（行を分けて縦に伸ばす）。吹き出し同士の隙間や名前の行から、チューブトップの線が覗きやすい
- その前のメッセージ（例：ケンジ「いただきました〜」）は、上の首元あたりに小さく置く
- チューブトップの位置はプロンプトで指定してもぴったりには揃わない。生成後に、吹き出しの位置と大きさを合わせる

## OpenAI（gpt-image-2、API直叩き）で試した結果（2026-10-30）
| 内容 | 結果 |
|---|---|
| 二人・上半身裸の雰囲気・布団と髪で胸元を隠す | 通った |
| 二人・女性は白いチューブトップ・腰まで | 通った（採用） |
| 二人・短いバンドゥでへそ出し・露出位置を細かく指定 | 入力の段階で拒否（moderation_blocked / sexual） |
| 女性一人・チューブトップでへそ出し・下半身は布団 | 通った。ただし絵柄が実写寄りになった |

- ChatGPT アプリでは断られた内容でも、API を直接呼ぶと通ることがある
- 「ベッド＋男女＋へそ出し＋露出位置の細かい指定」が重なると拒否されやすい
- 断られたら、言い換えてすり抜けることはしない。案を変えるか、別の生成手段（xAI、ローカルの ComfyUI）を検討する
- 「Japanese manga illustration style」と書いても、露出がある絵は実写寄りになりやすい。絵柄を揃えるなら設定画を参考画像として渡す
